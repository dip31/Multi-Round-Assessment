# Practice Mode - User Guide (Updated 2026-09-24)

## What's New?

Practice Mode is now **truly independent**! You can practice any round type in any order, as many times as you want, all within the same practice session.

---

## How Practice Mode Works Now

### Independent Selection
Choose **ANY** practice type at **ANY** time:
- 📝 MCQ Round (Aptitude questions)
- 💻 Technical MCQ (CS fundamentals)
- 🔀 Combined MCQ (50% Aptitude + 50% Technical)
- 🎯 Coding Challenge
- 💬 Interview Practice

### Repeatable
Complete a practice round and want to try again? Just click the same practice type:
- MCQ → Complete → MCQ Again ✅
- Coding → Complete → Coding Again ✅
- Interview → Complete → Interview Again ✅

### No Forced Progression
Completing one practice type does **NOT** force you into another:
- ❌ OLD: Complete MCQ → Forced into Coding
- ✅ NEW: Complete MCQ → Choose what's next

## Practice Types Explained

### MCQ Round
- **Focus:** Quantitative, Logical, Verbal, Reasoning
- **Duration:** ~20 questions
- **Difficulty:** Adaptive (gets harder/easier based on performance)

### Technical MCQ
- **Focus:** OS, CN, OOPS, DBMS, Data Structures
- **Subject Filter:** Choose specific topic or "All Technical"
- **Difficulty:** Adaptive

### Combined MCQ
- **Focus:** 50% Aptitude + 50% Technical
- **Questions:** Alternates between aptitude and technical
- **Best For:** Balanced practice

### Coding Challenge
- **Focus:** Algorithm problems
- **Features:** Full IDE, test cases, proctoring
- **Scoring:** Based on test case pass rate

### Interview Practice
- **Focus:** Technical, HR, or Communication interviews
- **Features:** AI-driven questions, contextual follow-ups
- **Best For:** Real interview preparation

## Tips for Effective Practice

### 1. Mix Your Practice
Don't just repeat the same type. Try:
- MCQ → Technical MCQ → Coding
- Coding → Interview → MCQ
- Build a balanced skill set

### 2. Use Repeat Practice Strategically
- Got a low score in Coding? Practice it again immediately
- Struggling with Technical concepts? Do multiple Technical MCQ rounds
- Need interview confidence? Repeat Interview practice

### 3. Check Your Progress
- After each round, review detailed results
- See which topics need more work
- Use insights to guide next practice choice

### 4. Take Breaks
- Practice sessions don't expire quickly
- Take breaks between rounds
- Come back refreshed for better performance

## Frequently Asked Questions

### Can I practice the same type multiple times?
**Yes!** Complete any practice and start it again immediately.

### Will my previous practice results be overwritten?
**No!** Every practice attempt is saved separately in your history.

### Do I have to complete rounds in a specific order?
**No!** Practice Mode has no required order. You choose what to practice next.

### What happens if I leave mid-practice?
Your session remains active. Return later to resume or start a new round.

### How is this different from Mock Drive?
- **Practice Mode:** Independent, repeatable, you choose order
- **Mock Drive:** Sequential (Aptitude → Coding → Interview), structured assessment
